# 血战文明 · 联机说明

## 1. 当前实现

- **模型**：服务器权威。第一轮使用监听服务器（主机玩家同时是服务器）+ IP 直连；UE 的 `IpNetDriver`，默认端口 UDP 7777。
- **会话流程**：主菜单 → 创建房间（`OpenLevel Battlefield?listen?mode=lobby`）→ 另一名玩家输入地址加入（`ClientTravel`）→ 双方准备 → 3 秒倒计时 → 服务器开始对局 → 结算 → 返回房间（重置准备状态，可再来一局）或返回主菜单。
- **房间规则**：最多 2 名玩家；第 3 人或对局进行中尝试加入会在 `PreLogin` 阶段被拒绝（客户端显示“加入失败：房间已满 / 对局正在进行”）。

## 2. 服务器计算或校验的内容

| 内容 | 位置 |
|---|---|
| 玩家归属与操作权限 | `ACWGameMode::PostLogin` 分配阵营写入 `ACWPlayerState`（客户端只读）；RPC 不含阵营参数 |
| 金币、经验、资源消耗 | `cw::Simulation::Check/Apply`（规则核心） |
| 训练队列与单位生成 | 规则核心 `StepTraining / TrySpawn` |
| 目标选择、伤害与死亡 | 规则核心 `StepUnits / StepProjectiles / DamageUnit / KillUnit` |
| 基地生命 | 规则核心 `DamageBase` |
| 时代升级 | 规则核心（经验、金币、未实装时代、升级中重复请求） |
| 技能冷却、费用、落点、效果 | 规则核心（含 NaN 与越界落点） |
| 胜负结算（只结算一次） | 规则核心 `EndMatch` + `ACWGameMode::EndMatch` 双重保护 |
| 指令频率 | `ACWPlayerController::ConsumeCommandToken`（令牌桶：每秒 15 个，上限 20） |
| 数据一致性 | GameState 下发数据 CRC，客户端不一致自动退出 |

客户端只负责：发送请求、显示复制下来的状态、播放动画/特效/音效、界面上的“能否操作”提示（提示不作为判定依据）。

## 3. 同步内容与频率

| 对象 | 方式 | 频率 |
|---|---|---|
| 单位（Id、阵营、行、兵种、X、生命、状态、攻击序号、受击序号、目标） | `ACWBattleReplicator` 中的 FastArray，只发送变化的单位 | 20 Hz |
| 投射物 | FastArray 只同步发射（起点、目标、速度、外观），飞行由客户端按相同速度表现；命中后保留 0.5 秒再移除，确保客户端至少收到一次 | 20 Hz |
| 阶段、倒计时、双方资源/时代/基地/队列/炮塔、技能预警、房间槽位、结算、统计 | `ACWGameState` 属性复制 | 20 Hz |
| 技能落地爆炸 | 不可靠多播（丢失只影响特效） | 事件 |
| 操作被拒绝的原因 | 可靠 Client RPC | 事件 |

攻击/受击用“序号变化”驱动表现：客户端在序号变化时播放攻击动作，动作的出手时刻等于数据表中的 `AttackWindup`，与服务器结算伤害或发射投射物的时刻一致。单位位置在客户端以不超过移动速度 1.6 倍的速度插值，偏差超过 4 米直接对齐。

## 4. 异常状态

| 情况 | 处理 |
|---|---|
| 连接中 | 主菜单显示“正在连接 地址 …（秒数）”，可取消 |
| 加入失败 | 地址无法连接 / 超时 / 被拒绝（房间已满、对局进行中）/ 版本不一致 → 返回主菜单并显示原因 |
| 对局中玩家离开或断线 | 服务器 `Logout` → 规则核心判离开方负 → 结算界面显示“对手离开了对局” |
| 倒计时中有人离开或取消准备 | 回到房间，取消倒计时 |
| 主机关闭 / 连接中断 | 客户端回到主菜单，显示“主机已关闭房间”或“连接中断：…”（连接超时 15 秒） |
| 比赛结束 | 结算界面：返回房间（联机）/ 再来一局（单人）/ 返回主菜单 |

## 5. 验证方法与结果记录

| 场景 | 方法 | 结果 |
|---|---|---|
| 本机多实例 | `Tools\civwar.ps1 nettest`：自动建房、加入、准备、双方机器人打完整局；比较双方 `CIVWAR_RESULT`（胜者、结算原因、双方基地生命、时代、训练数、击杀数）；客户端 `-cwcheattest` 发送非法指令并统计 `CIVWAR_REJECTIONS` | **公开源码版未复测** |
| 局域网（两台电脑） | A：`-cwhost`（或主菜单创建房间），B：`-cwjoin=A的局域网IP`；同样比较日志 | **未运行** |
| 公网 | 主机端口映射 UDP 7777 后由外网机器加入 | **未运行**；依赖网络环境 |

在安装引擎、实际跑过上述测试之前，不能认为联机已经验证；本机双窗口成功也不代表公网可用。

## 6. 公网、房间服务与 NAT 穿透（尚未接入）

直连模式下，公网联机需要主机具备可达的公网 IP 并做端口映射。要做到“房间列表 / 邀请 / 无需端口映射”，需要接入在线服务，下列任一方案都需要你提供账号或服务：

| 方案 | 需要提供 | 工作内容 |
|---|---|---|
| Epic Online Services（EOS） | Epic 开发者门户的产品、沙盒、部署 ID 与客户端凭据 | 启用 OnlineSubsystemEOS / EOS 插件；用 Session 接口实现创建/查找/加入；P2P 中继（EOS P2P）解决 NAT |
| Steam | Steamworks 应用 ID（需付费注册） | OnlineSubsystemSteam + Steam Sockets（SDR 中继）；好友邀请 |
| 自建服务 | 一台公网服务器 | 房间列表/撮合 HTTP 服务；专用服务器部署（需要源码版引擎构建 `CivWarServer` 目标）；中继或 STUN/TURN |

代码侧已预留：`CivWarServer.Target.cs`（专用服务器目标；Launcher 版引擎不支持构建）；GameMode 在专用服务器或 PIE 监听模式下自动进入房间模式；会话入口集中在 `UCWGameInstance::HostRoom / JoinRoom`，接入在线服务时替换这两处即可。
